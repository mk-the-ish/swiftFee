# **App Name**: SwiftFee Manager

## Core Features:

- Daily Exchange Rate Input: Allow the bursar to enter the daily exchange rate for USD to ZWG.
- Fees Payment Recording: Record student fees payments, including fee type (levy, tuition, building fund, exam fee), currency, amount, and bank account.
- Currency Conversion: Automatically convert payments made in ZWG to USD using the daily exchange rate.
- Student Owings Tracking: Maintain levy owing, tuition owing, building fund owing attributes for each student, and update them upon payment.
- New Term Billing: Allow the bursar to enter the amount each student should pay for each fee type for the new term, and update the owing amounts accordingly.
- Financial Statements Generation: Generate financial statements (powered by a tool). The AI tool analyzes recorded fees payments and calculates balances based on various criteria (fee type, date range, bank account) as determined from context.
- Bank Account Management: Define a choice of the bank accounts (bank, branch, account number and currency) the fees will be deposited to.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) for trust and security.
- Background color: Light Gray (#F0F0F5), to provide a clean backdrop.
- Accent color: Teal (#009688), providing a contrasting and complementary balance for interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look suitable for both headlines and body text.
- Use material design icons to represent payment types, settings, and other actions.
- Clean and structured layout with clear sections for data input, reports, and settings.
- Subtle transitions and animations to provide feedback on user actions and improve the overall user experience.
